# Divshot

> Divshot was a front-end / static web application hosting platform (Santa Monica, CA) offering
> git-style deploys of single-page and static apps across development, staging and production
> environments, custom domains, SSL, environment config, basic-auth protection and webhooks.
> It was backed by 500 Global, acquired by Google in 2015 and folded into Firebase Hosting.
> THE SERVICE IS DEFUNCT: divshot.com no longer resolves and the API host api.divshot.com is
> gone. Everything below is a historical record captured from surviving first-party sources
> (the npm registry and the github.com/divshot organization). None of it is callable.

## Status

- Status: defunct / end-of-life (probed 2026-07-20)
- Successor (reported): Google Firebase Hosting
- Website: https://divshot.com (does not resolve)
- Note: divshot.io now hosts an unrelated third-party WordPress placeholder

## API surface (historical)

The Divshot API was never published as OpenAPI. Its resource families, as documented by the
first-party divshot-api client: user (password, emails), organizations (members), apps, builds,
releases, domains, environment configuration, subscription, webhooks.

Authentication was a client_id plus either a password grant, a GitHub browser-popup flow, or a
bearer access token.
